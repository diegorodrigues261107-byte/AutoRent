Como usar

1. Cadastre um cliente ou escolha um já existente. 2. Escolha um automóvel. 3. Crie um pedido. 4. Entre como agente para avaliar. 5. Registre o contrato após a aprovação.

Os dados são persistidos pelo JSON Server. Para operações administrativas, selecione um agente.
